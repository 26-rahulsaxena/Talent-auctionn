Talent Auction – web version

Upload this whole folder to any static web host (Netlify Drop, GitHub Pages, Vercel, your own server).
Open index.html there. Online play: Choose your mode → Human vs Human · Online → Create lobby, then share the code or the invite link.
Opening index.html straight from your disk works for single-device play; online play needs it served over http(s).
Own signalling server (optional): add ?peer=host:port:/path:secure to the URL (see the main README).
